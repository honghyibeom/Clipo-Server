# SpringBoot-Project-SNS
스프링 부트 + SNS 프로젝트


## 🖥️ 프로젝트 소개
Thread Instagram 를 참고하여 만든 SNS 사이트입니다.
<br>

## 🕰️ 개발 기간
* 24.06.26일 - 22.05.24일

### 🧑‍🤝‍🧑 맴버구성
 - 팀원1  : 홍희범 - String-Boot Server
 - 팀원2  : 유현우 - React Client

### ⚙️ 개발 환경
- `Java 8`
- `JDK 1.8.0`
- **IDE** : STS 3.9
- **Framework** : Springboot(2.x)
- **Database** : Maria DB(11xe)
- **ORM** : JPA
